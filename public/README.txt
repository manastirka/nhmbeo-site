Files in this folder are copied verbatim to the site root.

If you prefer Google Search Console's "HTML file" verification method
instead of the meta-tag method, place the file Google gave you here.
For example, place `googled1234abc5678.html` in this folder; after the
next deploy it will be reachable at:
  https://your-domain.example/googled1234abc5678.html
and Search Console will verify your ownership.

The meta-tag method is set via the NEXT_PUBLIC_GOOGLE_VERIFICATION env
var (see .env.example).
